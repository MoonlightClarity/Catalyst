# Overnight coordinator integration — adversarial architecture review — 2026-09-11

Status: coordinator disposition of `OVERNIGHT_ADVERSARIAL_ARCHITECTURE_2026-09-11.md`. Research/design only; no GUI or product code.

## Decision
The adversarial review does not invalidate the Working Picture model, but it does expose several narrow assumptions that should be amended before deliberate closure. Architecture is therefore reopened only on these affected invariants; generic comparator research remains closed.

## Accepted clarifications
1. **The commitment ladder is an interaction progression, not a scalar data model.** Persistence, organizational explicitness, semantic explicitness, epistemic confidence, method status, scope, and publication readiness may vary independently. De-formalization and persistent ambiguity must remain possible.
2. **Authored geometry is formally non-assertive but pragmatically suggestive.** `move != relate` remains absolute in the record model, while shared/reviewed pictures must acknowledge that humans may infer meaning from proximity, enclosure, order, size, and alignment.
3. **Focus Context is restoration state, not a ban on comparison.** Side-by-side/coordinated comparison contexts are compatible when deliberately invoked and must still preserve return-to-context.
4. **Authored geography and diagnostic projections have different authority classes.** Derived/adversarial layouts may challenge bias but never silently overwrite the authored picture.
5. **Method provenance does not imply epistemic superiority.** Recording ACH or any other structured method must not visually imply the output is better supported merely because it is formal.
6. **Working Picture cannot be the only address space.** Outline/list/search/query/timeline/matrix/source index and keyboard navigation remain first-class alternate projections for task fit and accessibility.

## Narrow architecture issues reopened
- **Identity revision semantics:** shared identity across occurrences is necessary, but in-place shared-content edits can create distant-edit surprises and historical contradiction. Prototype modeling must separate stable referent identity from inspectable authored revision/version state, without deciding the final storage schema.
- **Contextual analytical role:** the same identity may have context-local roles/interpretations beyond geometry (for example background, key observation, counterexample). These must not silently become global identity semantics.
- **Semantic relation richness:** consequential relations should be first-class attributable assertions capable of scope, perspective, time/status, confidence/assessment and provenance; connector portrayal remains separate.

## Provenance and boundedness amendments
- **Source continuity has two strength classes.** The strongest path is an immutable retained source representation/version plus selectors. Live/external-source resolution remains best-effort and must preserve exact/degraded/ambiguous/unresolved recovery state rather than presenting recovered location as certainty.
- **Bounded Working Pictures require issue-level coverage outside the current desk.** A quiet global record/index or coverage cue must make relevant off-picture material discoverable so local focus does not imply global completeness. The exact UI remains a prototype question.

## Prototype falsification tests added
- Edit shared content through one occurrence and verify other contexts expose revision/history rather than changing invisibly.
- Reuse one identity under different context-local analytical roles and confirm those roles do not become intrinsic/global semantics.
- Create a consequential semantic assertion with author/scope/status and verify its local connector can disappear without losing the assertion.
- Put disconfirming material in a sibling subpicture and test whether issue-level coverage prevents false local completeness.
- Compare immutable retained-source return with mutated live-source recovery and require explicit resolution quality.
- Compare serial source focus/return with an intentional side-by-side comparison context for a task that needs simultaneous inspection.
- Apply a derived diagnostic layout to a confirmation-biased authored picture and verify the diagnostic can challenge the arrangement without overwriting it.
- Verify durable objects remain recoverable through non-spatial projections for users/tasks where spatial memory is weak.

## Closure impact
These are bounded amendments, not grounds for another broad research sweep. Deliberate research closure should wait for reconciliation of the pending interaction-pattern pass and either the authorized Trilium hands-on pass or an explicit decision to defer it. Production Working Picture code remains unauthorized; the implementation-primitives pass is feasibility evidence for the later disposable prototype only.
