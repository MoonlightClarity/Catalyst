# High-value source index

This is not an exhaustive bibliography of every web result in the conversation. It captures the sources that materially changed Catalyst's architecture or design direction, grouped by problem.

## Intelligence tradecraft and analytic standards

- **ODNI — ICD 203: Analytic Standards**  
  Key use: source information vs assumptions/judgments, uncertainty, alternatives, changes in judgments, dissent, effective visual information.
- **ODNI / NIC public assessments**  
  Key use: likelihood vs confidence, confidence basis, differing agency assessments.
- **CIA — Psychology of Intelligence Analysis (Richards Heuer)**  
  Key use: ACH, diagnostic evidence, missing evidence, assumptions, alternatives, analytic bias.
- **CIA — Tradecraft Primer: Structured Analytic Techniques**  
  Key use: brainstorming, assumptions, indicators/signposts, alternatives.
- **CIA warning / Strategic Warning literature**  
  Key use: linchpins, triggers, signposts, warning paradox, deception, changing indicators.

## Intelligence cartography, graphics, and publication practice

- **CIA — The Mapmaker's Craft: A History of Cartography at CIA**  
  Key use: intelligence cartography lineage, standardized symbols/labels, Arthur Robinson, visual communication.
- **CIA — A Day in the Life of a CIA Cartographer**  
  Key use: hierarchy through line weight, size, color, symbols; secondary information kept quiet.
- **CIA/NPIC publication and graphics guides**  
  Key use: economical annotation/color, source numbering, legends, briefing boards, representative/composite graphics.
- **CIA historical design-system review / graphics standards material**  
  Key use: legibility, centralized standards, typography/graphics consistency.
- **CIA Historical Staff style/source-reference material**  
  Key use: source-identification marks and recoverability.
- **ICD 206 / IC source-citation specifications**  
  Key use: traceability without exhaustive visible source metadata.

## Military / operational symbology and portrayal

- **MIL-STD-2525D / APP-06**  
  Key use: compositional frame/icon/modifier system, fixed modifier placement, scalable display hierarchy, line/area/point grammar, monochrome robustness.
- **NGA GEOINT Portrayal Focus Group**  
  Key use: portrayal explicitly treated as system-to-human interface and standardization problem.
- **Army doctrinal graphics / event templates / IPB**  
  Key use: overlays, indicators, discriminating differences, event/time matrices, task-specific visual geometries.
- **Marine intelligence link-analysis doctrine**  
  Key use: simple entity/relationship notation, association matrix vs link diagram.

## Icon/symbol human factors

- **FAA Human Factors Design Standard / icon guidance**  
  Key use: concrete/familiar icons outperform unnecessarily abstract forms, icon+label roles, discriminability.
- **ISO 9186 series**  
  Key use: separate comprehension, perceptual quality, and referent-association testing.
- **Military tactical-display “symbicon” research**  
  Key use: hybrids of recognizable pictorial form and coded symbolic information can outperform either alone for visual search.
- **Visual-search/salience/icon research**  
  Key use: salience, concreteness, familiarity, complexity, and set size affect search/recognition.

## Mind mapping, concept mapping, and spatial hypertext

- **DRDC — Concept Map Knowledge Model of Intelligence Analysis**  
  Key use: intelligence-specific interlinked concept maps, focus questions, multiple map structures, breaking one huge map into human-scale maps.
- **IHMC CmapTools / Novak & Cañas concept-map theory**  
  Key use: focus question, labeled propositions, cross-links, knowledge models.
- **XMind structure documentation**  
  Key use: multiple and mixed local structures rather than one universal layout.
- **TheBrain**  
  Key use: active-thought/focus navigation and local neighborhood rather than full graph visibility.
- **Freeplane clones/shared nodes**  
  Key use: same underlying thought represented in multiple contexts.
- **Obsidian Canvas / JSON Canvas**  
  Key use: nested canvases and separation of layout/view from underlying notes.
- **Scapple**  
  Key use: deliberately permissive spatial sensemaking before formal hierarchy.
- **Tinderbox / VIKI spatial hypertext research**  
  Key use: emergent/provisional structure through spatial arrangement.

## Visual analytics / sensemaking

- **PNNL — Space to Think**  
  Key use: analysts use spatial layout as external memory and sensemaking structure.
- **PNNL — Scalable Reasoning System**  
  Key use: evidence, assumptions, hypotheses, reasoning artifacts linked back to originating analysis.
- **Jigsaw (Georgia Tech / Stasko)**  
  Key use: coordinated text/list/graph/timeline views, visual index into source reports, analyst evaluation feedback.
- **Shneiderman — semantic substrates / overview-zoom-filter**  
  Key use: meaningful spatial regions, filtering, large networks.
- **Pad++ / zoomable interfaces**  
  Key use: semantic zoom and animated orientation-preserving navigation.
- **Microsoft Data Mountain / Time Quilt**  
  Key use: spatial memory, representative thumbnails, limitations of tiny thumbnails at scale.

## Provenance, annotation, and preservation

- **W3C Web Annotation Data Model**  
  Key use: exact source selectors, quote/prefix/suffix/context, source version/state.
- **W3C PROV**  
  Key use: entity/activity/agent/derivation distinction; revision, quotation, invalidation concepts.
- **PREMIS (Library of Congress)**  
  Key use: fixity, objects/versions, events, agents, preservation history.
- **C2PA**  
  Key use: provenance/integrity versus truth; preserving prior provenance through transformations.
- **NIST / SWGDE digital evidence guidance**  
  Key use: hashing/fixity, working copies, chain-of-custody boundaries, repeatable transformations.

## Corroboration / source independence

- **WMD Commission report**  
  Key use: repeated reports from one source can masquerade as independent corroboration; circular reporting.
- **Cochrane Handbook / retraction processes**  
  Key use: multiple reports may derive from one study; preserve derivatives without counting them independently; downstream impact review after retraction.
- **National Academies intelligence-analysis reviews**  
  Key use: independent triangulation, collaboration, dissent, distributions of judgments.

## Early warning / weak signals

- **CIA strategic warning / warning indicator literature**  
  Key use: early warning under uncertainty, linchpins, signposts, rate of change, deception, crying-wolf problem.
- **EU/JRC horizon scanning**  
  Key use: “signs of new,” clustering, bottom-up weak-signal interpretation.
- **Policy Horizons Canada / Sitra / OECD foresight**  
  Key use: weak signals, novelty, emergence, opportunity as well as risk.
- **WHO / CDC early-warning surveillance**  
  Key use: verified/rejected/undetermined states, clusters of individually inconclusive signals, false-alert fatigue, baseline deviations.

## Product precedents / graph tools

- **IBM i2 Analyst's Notebook**  
  Key use: semantic entity/link types, multiple representations, icon frames, event frames/theme lines, pictures plus attribute glyphs.
- **Maltego Graph**  
  Key use: investigation graph and entity typing, but also a warning against icon proliferation.
- **ArcGIS Intelligence / Knowledge**  
  Key use: multiple link-chart layouts, selection vs filtering, chronological layouts, explicit graph-analysis lenses.
