# Catalyst Firefox extension privacy

Catalyst is local-first.

The Firefox extension does not collect, transmit, sell, share, or monetize user
data. It does not use analytics, advertising, telemetry, remote logging, or a
hosted application backend.

Catalyst requests no browsing-history permission and no website host
permissions.

PDFs opened by the user are processed locally in Firefox. Notes, Outline
content, Methods responses, annotations, cached document data, and session state
remain in local browser storage unless the user explicitly saves or exports a
file.

The user can explicitly export Catalyst session XML, PDF, DOCX, or RTF files.
Those files are written to a location chosen by the browser/user and are not
sent to Catalyst or any third party.

Catalyst bundles its application code and PDF engine resources locally. The
extension does not load remote executable code.

If Catalyst's data practices change in a future release, this document and the
Firefox manifest data-collection declaration must be updated before that
release is distributed.
