## Maintenance rules

1. New reusable UI symbols belong in `src/ui/CatalystSymbols.tsx`.
2. Analytical meaning should be encoded by glyph geometry first; color is supplementary.
3. Reusing one glyph for unrelated meanings should be treated as an iconography conflict.
4. Direct inline SVG is acceptable for diagrams and portrayal primitives, but ordinary UI controls should use the registry.
5. Run `npm run icons:audit` after icon additions, removals, or major UI restructuring.
