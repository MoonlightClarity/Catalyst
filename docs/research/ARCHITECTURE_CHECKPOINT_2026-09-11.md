## Durable synthesis

Primary output: `PASS-2026-09-11-architecture-synthesis-identity-placement-provenance.md`.

Core result: Catalyst should explicitly separate six concerns: identity; occurrence/placement; structural membership; semantic relation; provenance; focus-in-context.

The Working Picture should be a contextual portrayal layer over durable analytical identities, not the canonical ontology itself.

## Evidence that materially changed the model

- Freeplane: same identity across map/outline, but free placement can conceal parentage. Catalyst must not infer or hide structural commitment beneath spatial freedom.
- Zotero: source identity and exact source location survive extraction; provenance is reversible navigation, not just citation text.
- Trilium: one note ID can have multiple branch records under different parents. This directly validates identity-versus-occurrence, while also showing why Catalyst must go beyond hierarchical occurrence.
- AFFiNE / BlockSuite: page and edgeless portrayals share identity; geometry, frames, and explicit groups are distinct states.
- Logseq: reference, editable embed, and transformed derivative should be distinct reuse/provenance behaviors.
- Excalidraw: connector binding is portrayal mechanics, not semantic truth; relation identity should survive connector rerouting/hiding/deletion of portrayal.

## Required invariants

Move != relate. Enclose != necessarily contain. Contain != assert. Reuse != copy. Extraction != provenance severance. Projection != conversion. Focus != structure. Auto-layout must not overwrite authored geography.

## Scope/anchor/focus resolution

Added `PASS-2026-09-11-architecture-resolution-scope-anchor-focus.md`.

Resolved defaults:
- Working Picture organization is context-scoped, normally via occurrences/membership instances; organizing one reuse must not globally reorganize all reuses of an identity.
- Semantic analytical relations normally target durable identities, with separate local connector portrayals.
- Source handling separates Source Identity, precise Source Anchor, and any durable Anchored Analytical Identity created when a region/excerpt becomes placed/reused/annotated/related.
- A transient selection/anchor need not become a permanent analytical object.
- Analyst observation/interpretation derived from a captured source region should be a separate identity with provenance, preserving the source/analyst boundary.
- Ordinary focus is session/restoration state; explicit `save view`-type promotion creates a durable Saved View/Viewpoint rather than turning navigation noise into analytical content.

Natural scope summary: identity = globally durable; provenance anchor = source/version scoped; structure = analytical-context scoped; semantics = identity scoped; portrayal = occurrence scoped; focus = session/context scoped until explicitly promoted.

## Command-semantics follow-on

Added `PASS-2026-09-11-architecture-command-semantics.md` and updated the Working Picture architecture contract.

Resolved familiar editor actions that could otherwise collapse the model:
- editing durable content through an occurrence edits the shared identity;
- editing geometry/local representation edits only that occurrence;
- `Reuse` creates another occurrence of the same identity;
- `Move occurrence` relocates context-local portrayal without identity change;
- `Fork/Duplicate as new object` intentionally creates a new identity with lineage where analytically relevant;
- generic copy/paste must not hide which identity behavior occurred;
- manual edits after a reproducible transformation must remain visible in provenance/history rather than masquerading as untouched method output.

These rules extend the mutation discipline into ordinary canvas/editor commands.
